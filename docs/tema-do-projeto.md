# Conecta Campus

## Problema
Alunos ingressantes nem sempre encontram rapidamente ambientes, serviços, horários e recursos de acessibilidade do campus.

## Público-alvo
- Estudantes ingressantes
- Pessoas que precisam localizar recursos acessíveis
- Visitantes em atividades acadêmicas

## Objetivo geral
Criar um guia web simples, responsivo e acessível para consultar locais e serviços acadêmicos.

## Primeira versão
A versão 1.0 usará HTML, CSS e JavaScript, com pesquisa, filtros e favoritos armazenados no navegador.

## Continuidade
No segundo semestre, a solução evoluirá para Node.js, React, TypeScript, Tailwind CSS e publicação na Vercel.
